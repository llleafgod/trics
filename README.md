# TRACE-CPS Ontology

TRACE-CPS Ontology is a cross-domain ontology for Cyber-Physical System (CPS) security. It provides a unified semantic model for representing cyber threats, vulnerabilities, industrial assets, and cross-domain relations between IT-side threat intelligence and OT-side physical assets.

The ontology is designed to support CPS security knowledge graph construction (including ontology-guided information extraction, graph fusion and completion pipelines) and graph-based threat analysis and risk assessment.
